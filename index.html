1. Cargar archivo

Selecciona el archivo original de asistencias

El archivo se procesa en tu navegador. Se necesita conexión a Internet para cargar la biblioteca de Excel. Después de abrir este HTML, selecciona tu archivo de asistencias para habilitar la vista previa, los gráficos y la descarga.

2. Elegir columnas para el Excel

Las cuatro columnas principales siempre se incluirán. Marca o desmarca las columnas adicionales según lo que necesites.

3. Ordenar los resultados

El orden se aplica tanto a la vista previa como al Excel descargado. Los carnés se ordenan numéricamente cuando contienen números; los porcentajes se comparan por su valor numérico.
